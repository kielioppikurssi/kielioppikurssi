🇸🇪 OmistA lyhyesti

Kultainen sääntö: Omistuspronominin jälkeen adjektiivista tulee aina määräinen -a-muoto, mutta substantiivi jää lyhyeksi eli epämääräiseksi (ei loppuartikkelia)!
omistussana + adjektiivin -a-muoto + epämääräinen substantiivi
Yksikkö: Sininen = min/mitt/mina Vihreä = din/ditt/dina Turkoosi = hans Roosa = hennes Keltainen = hens
Monikko: Indigo = vår/vårt/våra Oranssi = er/ert/era Violetti = deras
Oikein: 0 Putki: 0 🔥 Väärin: 0
📚 Hjälp: Kaikki omistuspronominit (yksikkö & monikko)

Kaava: omistuspronomini + adjektiivi (-a / lilla / små) + substantiivi (epämääräinen)
Esim. min röda bil (punainen autoni), mitt stora hus (iso taloni), deras nya böcker (heidän uudet kirjansa).
