📚 Muistilista: Monikon nominatiivi (Именительный падеж мн. ч.)

Suku Kova vartalo (kova pääte) Pehmeä vartalo / 7 kirjaimen sääntö (pehmeä pääte) Yleisiä poikkeuksia
Maskuliini
(konsonantti, -й, -ь)		 Pääte: -ы
стол → столы
отец → отцы (liikkuva е) 		Pääte: -и
• pehmeät (-ь, -й): преподаватель → преподаватели
• 7 kirjaimen sääntö: мальчик → мальчики, товарищ → товарищи 		• Pääte -а / -я: город → города, дом → дома, учитель → учителя, директор → директора
• Pääte -ья: брат → братья, сын → сыновья, муж → мужья
• Eri sana: человек → люди, ребёнок → дети
Feminiini
(-а, -я, -ь)		 Pääte: -ы
комната → комнаты
газета → газеты 		Pääte: -и
• pehmeät (-я, -ь): неделя → недели, жизнь → жизни
• 7 kirjaimen sääntö: книга → книги, ручка → ручки, улица → улицы (ц + ы!) 		• Vartalon pidennys: мать → матери, дочь → дочери
• Pääte -ья: статья → статьи
Neutri
(-о, -е, -мя)		 Pääte: -а
слово → слова
окно → окна 		Pääte: -я
море → моря
здание → здания
платье → платья 		• -мя-sanat (-ена): время → времена, имя → имена
• Pääte -ья: дерево → деревья
• Taipumattomat: пальто, метро, кафе (eivät muutu!)

✍️ 7 kirjaimen oikeinkirjoitussääntö

Kirjainten г, к, х, ж, ч, ш, щ jälkeen ei koskaan kirjoiteta kirjainta ы, vaan aina и:

  • девушка → девушки
  • ученик → ученики
  • товарищ → товарищи

🎨 Adjektiivit monikon nominatiivissa

Adjektiiveilla on monikossa kaikille suvuille vain kaksi mahdollista päätettä:

  • Kova vartalo → -ые: новый стол → новые столы
  • Pehmeä vartalo tai 7 kirjaimen sääntö → -ие: хороший → хорошие, маленький → маленькие, синий → синие
